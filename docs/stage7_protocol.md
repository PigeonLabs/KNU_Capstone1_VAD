# 7단계 사전 규약

2026-09-25 사용자가 7-1·7-2·7-3 전체 실행 승인. R01–R04만 사용하고 seed 0·1·2, 기존 정상 학습 80%/보정 20%를 유지한다. 모든 원본·기존 결과 보존, 10 GiB 이하 중지 및 자동 재개 금지. 단계 완료 후 분석·코드·로그·SHA256만 main에 자동 게시한다. 예약 모니터를 생성하지 않는다.

## 7-1 원인 분해

B/k10 및 S/k5 FP32의 5단계 고정 모델과 점수를 재사용한다. 새로운 학습이나 임계값 튜닝을 하지 않는다. 외형 단독·시간 단독·결합의 AUROC/AUPRC와 각각 정상 보정 q99.5 + 3연속 경보를 비교한다. 유효 평가 frame 및 R02 12/13/14 제외를 유지한다. 영상별 정상 보정/테스트 정상/테스트 이상 점수 분위수, 정상 보정 영상에서 상대 주기에 대한 위상 오차와 위상 점프, 오경보 연속 길이와 발생 횟수, 미탐 구간의 점수 초과 여부를 기록한다. 테스트 라벨을 사용하는 부분은 사후 진단이며 모델·설정 선택용 검증셋이 아니다.

7-1 결과를 읽고 7-2의 개선 대상과 이유를 별도 decision.json에 기록한다. 기존 테스트를 이미 관찰했으므로 후속 개선은 탐색적 연구이며 새로운 독립 테스트 성능으로 주장하지 않는다. 정상 분포의 지속적인 차이는 단순 경보 평활로 해결된다고 가정하지 않는다.

## 7-2 범위 확정 원칙

시간 위상 추정 자체가 주요 병목이면 정상 데이터만 사용하는 연속 위상 모델을 검토한다. 경보 규칙과 정상 보정 분포가 주요 병목이면 모델을 고정하고 causal 경보 규칙을 비교한다. 실행 전 구체적 후보와 정상 CV 선택 규칙을 이 문서에 추가하고 커밋한다. 테스트 라벨로 후보 숫자·분위수·평활 계수를 선택하지 않는다. 기존 기준선은 항상 보존한다. 오경보 횟수와 활성 경보 FPR, 미탐과 탐지 지연을 함께 평가한다. 지속 시간을 늘려 횟수만 줄인 경우를 동시 개선으로 주장하지 않는다.

## 7-3 전체 영상 batch-1 검증과 정상 보정 구성 민감도

고정 B/k10 모델에 FP32 전체, BF16 전체, BF16 백본·메모리 + FP32 위상 head의 세 가지 정밀도 구성을 비교한다. RGB·특징 정규화와 cosine 누산은 FP32. 새로운 모델 학습 없음. 3 seed, 4개 장면의 정상 보정 및 전체 테스트를 원본 JPEG에서 frame 1개씩 실제 추출한다. 영상 경계에서 상태를 reset하고 첫 35프레임을 warmup으로 처리한다. 세 seed/head를 공유 추출로 평가하는 정확도 패스는 속도 측정으로 쓰지 않는다. 특징 바이너리 캐시를 새로 만들지 않고 영상별 특징 SHA256과 raw frame 점수를 기록한다.

정상 보정은 각각의 batch-1 경로에서 새로 적합한다. 6단계 batch 추출 평가와 공통 프레임에서 점수·phase·AUROC·경보 차이를 비교한다. 혼합 head와 BF16 전체를 비교하되 동일 백본의 수치 변화까지 해결한다고 가정하지 않는다.

속도/실제 경보는 별도 seed0의 단일 모델로 원본 JPEG 전체 유효 테스트 영상 capacity 1회, 장면별 가장 긴 유효 테스트 영상 전체 30 FPS paced replay 1회. 매 영상 reset, 정상 train 영상 36프레임으로 GPU warmup. read/decode·전처리·백본·head·메모리·시간 검사·고정 경보·CUDA 동기화까지 측정한다. GPU peak allocated/reserved와 frame별 지연·대기·33.3ms 기한 초과를 기록한다. 전체 영상 batch1 정확도 패스와 전용 속도 패스의 위상/점수를 검산한다. 다른 프로젝트 GPU 프로세스를 종료하지 않고 환경을 기록한다. 실제 카메라·네트워크·다른 장비로 일반화하지 않는다.

정상 보정 영상 하나씩 제외한 통계·임계값에 따른 heldout 정상 오탐 및 동일 테스트 성능 변동을 보고한다. 정상 80% 모델 자체의 재학습 분할 검증은 아니며, 정상 보정 집합 구성 민감도이다. 테스트 성능으로 어느 분할을 선택하지 않고 모두 보고한다. 공통 frame35..N-18, 경보35..N-1, R02 ±1 민감도 유지.
