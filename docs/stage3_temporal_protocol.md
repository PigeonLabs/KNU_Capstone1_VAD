# 3C 정상 holdout 시간 변형 진단 규약

3A/B에서 정한 특징·메모리·head를 변경하지 않는다. 실제 이상 유형 정답이 없는 상황에서 원리만 검증한다. 파생 영상을 새로 저장하지 않고 원본 특징의 index mapping을 manifest로 저장한다. 새로운 학습이나 실제 테스트 라벨은 사용하지 않는다.

- 각 정상 holdout 영상의 중앙에서 길이 12%(최소20프레임) 구간을 대상으로 정지(동일 프레임 반복 삽입), 역순(해당 구간 반전), 단계 건너뛰기(구간 제거)를 만든다.
- 입력은 변형된 순서의 16 CLS, 외형 특징은 같은 변형의 중앙 프레임 patch이다. 따라서 시간 순서를 바꾼 후 clip을 다시 구성한다.
- 원본과 0.9/1.1배 속도 변형은 별도 대조군이다. ±10% 속도 변화를 정상 허용 범위로 보는 것은 진단 가정이며 기업 공정 규격이 아니다.
- 비교 점수: 무조건부 외형, top3 가중 외형, 기존 5-window 위상 진행 잔차, 21-window 위상 진행 잔차, 외형/21-window 점수의 정상 p95 기준 비율 최댓값.
- 정상 기준 주기는 development 학습 영상 길이 중앙값에서 계산한다. 미래 프레임을 포함하는 offline 진단이며 실제 온라인 탐지 지연을 주장하지 않는다.
- event 구간과 clip/window 의존 범위가 겹치는 프레임을 진단 양성으로 정의한다. 최대 ±18프레임 범위를 사용하며 모든 점수에서 동일한 유효 프레임을 평가한다. skip은 jump 위치 주변이 탐지 기회이다. 이 라벨은 실제 이상 프레임 라벨이 아니다.
- 장면·변형별 AUROC/AUPRC, 원본 holdout 점수 p95 임계치에서 알림 비율·양성 재현율을 보고한다. 임계치 보정과 정상 오탐 계산에 같은 holdout을 사용하므로 오탐 수치는 독립 검증이 아니다.
- 실제 이상 유형 구분 성능이나 온라인 실시간성은 주장하지 않는다. 원본 프레임과 기존 특징 캐시는 변경하지 않는다.
