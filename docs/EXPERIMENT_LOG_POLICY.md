# 실험 기록·GitHub 게시 규칙

사용자 지정 저장소: https://github.com/PigeonLabs/KNU_Capstone1_VAD (`main`).

## 단계 정의

1. **논문 방법론 재현**: R01–R04 독립 50-epoch 학습 및 재구성·주기 점수 평가.
2. **DINOv2 도입**: 입력–복원 특징 비교와 디코더 없는 위상 조건부/무조건부 prototype 비교.
3. **위상 조건의 유효성 검증**: 별도 제안서. 사용자 선택 전에는 신규 실험을 실행하지 않음.

기존에 예약된 메모리 제거 학습은 **1단계 추가 ablation**으로 분류합니다. 3단계 결과로 혼동하지 않습니다.

## 반드시 보존할 자료

- 데이터 장면/영상/프레임 식별자, 정상 영상 분할, 라벨 정책, seed, 환경/소스 해시.
- 실제 실행 명령, 시작/종료·실패 상태, 전체 stdout/stderr 로그, 학습 손실 및 설정.
- 평가 프레임별 정답·원 점수·정규화/결합 점수, AUROC/AUPRC, 제외 영상 및 정렬 민감도.
- checkpoint·feature cache·원본 데이터의 상대 경로, 크기, SHA256. 바이너리는 로컬 보존.
- 메모리/처리시간 측정 범위, 재현 가정, 실패·수정·재개 이력.

**소급 한계:** 첫 두 단계의 원 모델 stdout은 25배치 간격, epoch 요약은 매 epoch 기록입니다.
프로토타입 분류기는 epoch 요약을 기록했습니다. 기록하지 않은 과거의 개별 배치 손실은 복원하거나 만들어 넣지 않습니다.
이 지시 이후 시작하는 원 모델 학습은 `batch_history.jsonl`에 매 배치의 영상/프레임·손실·gradient를 기록합니다.

## 게시

- 분석 가능한 원 CSV·JSON·JSONL·로그는 `experiments/`에 단계별 snapshot으로 보존합니다.
- README는 snapshot에서 자동 생성하여 실험 개요·진행방법·단계별 결과·미완료 사항을 표시합니다.
- 완료된 실행 단위마다 snapshot을 갱신하고 `main`에 commit/push합니다. 실패도 별도 기록합니다.
- push 전 remote를 fetch하여 선형 진행이 가능한지 확인합니다. 원격 이력을 강제로 덮어쓰지 않습니다.
- push 실패 시 게시 실행기는 중지하고 로컬 commit과 오류 로그를 남깁니다. 실행 중인 학습은 보존하며 상태 보고 자동화가 실패를 알립니다.
- 원본 이미지, PDF/문서, 모델/캐시 바이너리, 가상환경, 인증 정보는 게시하지 않습니다.
- `artifacts.jsonl`은 파일을 제공하는 다운로드 링크가 아닙니다. 외부 저장소 업로드는 이번 범위에서 제외합니다.
