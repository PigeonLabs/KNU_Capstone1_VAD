# 게시 재시도

최초 게시는 여유 공간 16.77GiB 상태에서 전체 기존 분석 아카이브 약 2.5GiB의 3배를 추가 사용한다고 계산하여 차단됐습니다. 실제 디스크 10GiB 경계 도달이나 실험 일시중지는 없었습니다.

게시자의 추가 사용량 추정을 Git 추적 변경 파일·신규 비무시 파일·이미 staged된 파일 크기의 3배 + 64MiB로 수정했습니다. 기존 10GiB 여유 기준, latched pause 금지, 파일 복사 전 여유 검사, push 전 검사, 강제 push 금지는 그대로 유지합니다. 원본 및 이전 결과를 삭제하지 않았습니다. 첫 실패 로그를 보존하고 동일 결과를 재게시합니다.
